# Quantum–Hybrid Dicentric Chromosome Scoring for Cytogenetic Biodosimetry

Code for the paper:

> **Feasibility of Quantum–Hybrid Dicentric Chromosome Scoring for Cytogenetic Biodosimetry**
> Marek Sokol, Jan Hejda, Petr Volf, Aleš Tichý, Patrik Kutílek
> Faculty of Biomedical Engineering, Czech Technical University in Prague
> IEEE Healthcom 2026

---

## Overview

The pipeline scores each chromosome crop as dicentric (DC) or monocentric (MC) using a frozen ResNet-18 backbone feeding an 8-qubit variational quantum circuit, then estimates the per-metaphase DC count with a classical random-forest regressor. Hardware inference runs on IBM Kingston (IBM Heron r2) via IBM Quantum cloud.

```
Metaphase image
    └─► per-chromosome crops (64×64, from YOLO bboxes)
            └─► frozen ResNet-18  (512-d features)
                    └─► projector  (512 → 64 → 8, 33 352 params)
                            └─► 8-qubit VQC  (48 params, 3 layers)
                                    └─► sigmoid head → P(DC) per crop
                                            └─► random-forest regressor
                                                    └─► DC count per metaphase
```

## Environment setup

### Python

Python 3.10+ recommended. Create and activate a virtual environment:

```bash
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

> **RTX 5090 / Blackwell (sm_120):** PyTorch must be built against CUDA 12.8 or newer.
> Standard `pip install torch` will not work. Use:
> ```bash
> pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
> ```

Verify GPU and quantum environment:

```bash
python scripts/verify_env.py
```

### IBM Quantum credentials

Required only for hardware inference. Save your API token once:

```python
from qiskit_ibm_runtime import QiskitRuntimeService
QiskitRuntimeService.save_account(channel="ibm_quantum", token="YOUR_TOKEN", overwrite=True)
```

Credentials are stored in `~/.qiskit/qiskit-ibm.json`.

## Running the pipeline

All scripts are run from the repository root with the virtual environment active. Scripts that train models accept `--fold N` to run a single fold; the default loops over all 5.

### Data preparation

```bash
python scripts/inventory_data.py       # EDA and label verification
python scripts/ingest_web3_dedupe.py   # Cross-source deduplication (run once)
python scripts/extract_crops.py        # Extract 64×64 per-chromosome crops
python scripts/make_splits.py          # 5-fold CV splits at image level
```

### Training

```bash
# Classical baselines
python scripts/train_instance_classifier.py [--fold N]
python scripts/train_classical_mil.py        [--fold N]
python scripts/train_vgg19_baseline.py       [--fold N]

# Quantum scorer
python scripts/pretrain_quantum_instance.py  [--fold N]
python scripts/aggregate_qinst.py

# DC count regressor
python scripts/count_regressor.py
```

### Hardware inference (IBM Quantum)

> Always run without `--submit` first (dry-run default) to check shot and QPU estimates before submitting.

```bash
python scripts/select_backend.py --backends ibm_kingston ibm_miami
python scripts/evaluate_qinst_hardware.py --device ibm_kingston --fold N          # dry-run
python scripts/evaluate_qinst_hardware.py --device ibm_kingston --fold N --submit
```

If post-processing crashes after a successful IBM job, recover via the saved job ID:

```bash
python scripts/recover_job.py --job-id <ID> --fold N --device ibm_kingston --bag-id web/12
```

## Key results

| Method | Scorer params | Strict-fold AUROC |
|--------|--------------|-------------------|
| VGG-19 (CNN) | 20.2 M | 0.972 ± 0.028 |
| ResNet-18 (CNN) | 8.4 M | 0.889 ± 0.013 |
| Classical-33k head | 33 001 | 0.881 ± 0.019 |
| Classical-48 head | 51 | 0.875 ± 0.034 |
| QInstance (VQC, **ours**) | **48** | **0.855 ± 0.018** |

DC count regression (random forest, 5-fold CV): **MAE 0.79** vs baseline 1.26 (−37 %).

Hardware fidelity on IBM Kingston (Heron r2): |Δp|_mean = 0.048 over 3 711 chromosomes.

## Configuration

All hyperparameters and paths are centralised in `utils/config.py`. Edit there — never hard-code values in scripts. Default seed: **42**. Every result file records timestamp, seed, and config hash.
